# JB Advisory — Global Business Network

An interactive, configurable global business directory demo built for **JB Advisory LLC**. Developed independently from any JB Advisory client systems or proprietary code.

> **Status:** Checkpoint 2 (geographic map) complete. The map now renders real country/territory boundaries joined to all 22 UN M49 subregions, with hover and click-to-select region highlighting, labels, and zoom/global-view controls. Search, filters, and the business directory land in Checkpoint 3.

## Stack

- [Vite](https://vite.dev/) + TypeScript (no UI framework)
- [Mapbox GL JS v3](https://docs.mapbox.com/mapbox-gl-js/) for the map
- [Sarala](https://fonts.google.com/specimen/Sarala) (Google Fonts) for typography
- Static JSON data, no backend

## Project structure

```

  filters/      pure filter functions (Checkpoint 2)
  map/          Mapbox init + style building
  components/   UI components
scripts/

```

## Local development

1. `npm install`
2. Copy `.env.example` to `.env.local` and set your Mapbox public token:
   ```
   VITE_MAPBOX_TOKEN=pk.your_token_here
   ```
   `.env.local` is gitignored — never commit a real token.
3. `npm run dev`

## Deployment (GitHub Pages)

Deployment is automatic via `.github/workflows/deploy.yml` on every push to `main`, and can also be triggered manually from the Actions tab.

**One-time repository setup (required before the first deploy):**

1. **Settings → Pages → Source:** select **GitHub Actions**.
2. **Settings → Secrets and variables → Actions → Variables tab → New repository variable:**
   - Name: `VITE_MAPBOX_TOKEN`
   - Value: your Mapbox public (`pk.`) token
   - It's stored as a *variable*, not a *secret*, because Mapbox public tokens are meant to ship in client bundles — restrict it by URL in the Mapbox dashboard (see below) rather than treating it as confidential.
3. Push to `main`. The workflow builds with that token baked in via Vite's `import.meta.env.VITE_MAPBOX_TOKEN` and publishes `dist/` to Pages.

Live URL once enabled: `https://jbadvisoryllc.github.io/jba-interactive-directory/`

**Restrict the Mapbox token:** in the Mapbox dashboard, add a URL restriction for `https://jbadvisoryllc.github.io/*` so the token only works from this site.

### Base path

`vite.config.ts` sets `base: "/jba-interactive-directory/"` to match this repo's Pages URL. If the repo is ever renamed, update that value (and the Mapbox token's URL restriction) to match.

## Geographic data — known edge cases

Boundaries are generated by `scripts/build-geo.mjs` from Natural Earth's public-domain 1:50m *admin-0 map units* layer (not the "countries" layer, which would bundle overseas territories into their parent country's shape and misassign their subregion). Run `npm run build:geo` to regenerate `src/data/geo/countries.topo.json`; it fetches from a commit-pinned URL for reproducibility and prints a validation report (feature count, per-subregion counts, excluded features, antimeridian ring check). The current output: all 265 source features resolved, all 22 subregions have at least one feature, zero antimeridian anomalies.

Country/territory → M49 subregion assignment lives in `src/data/geo/country-subregion.json` (`mapping`, keyed by ISO 3166-1 alpha-3). A few cases don't resolve from a plain ISO code and are handled explicitly there:

- **`disputedTerritoryOverrides`** — Natural Earth features with no usable ISO code at all (Kosovo, Somaliland, Northern Cyprus) are assigned to the M49 subregion of the territory they sit within, for map coloring only — not a statement on sovereignty.
- **`excludedFeatures`** — rendered as neutral, non-interactive land, like Antarctica: Antarctica itself, South Georgia & the South Sandwich Islands, and Heard Island & McDonald Islands (all uninhabited and outside the M49 country list), plus Siachen Glacier/Kashmir (an indeterminate territory in Natural Earth's own data, not a country).
- **Taiwan** is not listed in the M49 standard; it's placed in Eastern Asia, consistent with common UN statistical groupings.
- **Antimeridian-crossing regions** (Eastern Europe/Russia, Australia and New Zealand, Melanesia, Polynesia) use hand-set camera bounds in `m49-subregions.json` rather than computed bounding boxes, so selecting them doesn't zoom out to the whole globe. Natural Earth splits these features' geometry at the date line at source — `build-geo.mjs` also runs a ring-continuity check as a safety net and reports any anomalies.

### Map interaction (Checkpoint 2)

- Hovering or clicking a country highlights its whole M49 subregion in turquoise (not just that one country) — region borders, not individual countries, are the unit of interaction.
- Clicking a region flies the camera to its bounds. The "return to global view" control (next to zoom, top-right) resets the camera and clears the selection.
- All subregions share the same neutral land color; turquoise is reserved for hover/selection, per the approved design — no rainbow region coloring.
